  4. **WebUI cache lưu cả câu trả lời tự khai là hỏng.** Cache nói "chỉ lưu answer thành công, vì lưu failure sẽ hiện lỗi cũ sau khi daemon sống lại" — nhưng nó quyết định bằng **exit code**, trong khi `graph` cố ý trả `ok:false` + exit 0 để WebUI còn render được trang giải thích (exit khác 0 ⇒ server trả 502 và **không parse body**, tức là mất đúng cái trang đó). Sửa ở cache (`isCacheable` đọc cả body), **không** đổi exit code của graph.

  Đã ghi contract ba hình dạng vào header CLI: **single read** (fail là câu trả lời, exit 3) / **fan-out** (giữ body render được + exit 0, `ok` báo độ đầy đủ, `degraded` liệt kê chỗ thiếu) / **text relay** (`activity` relay nguyên văn output của agent, bytes lạ vẫn là câu trả lời hợp lệ, chỉ cần nằm trong JSON envelope).

  **Ba lần test của tôi tự claim quá lời trong một lượt** — đáng ghi hơn con số: (a) assert `!path.includes("..")` để chứng minh không escape thư mục skills — `path.join` chuẩn hoá mất `..` nên **xoá hẳn `safeName` vẫn pass**; phải đổi sang resolve rồi so prefix; (b) test traversal cho `skills read` trỏ vào file **không tồn tại**, nên nó fail vì lý do khác — xoá guard vẫn pass; phải tạo file thật ngoài thư mục; (c) gộp `models`/`graph`/`activity` chung một "hình dạng" nên pin sai contract cho cả ba. Cả ba chỉ lộ ra nhờ mutation, không nhờ suite xanh.
